# Zhou Yi Kelvin — Personal Portfolio

A responsive, static portfolio for [zhouyikelvin.github.io](https://zhouyikelvin.github.io).

## Files

- `index.html`: content, semantic page structure, and metadata.
- `styles.css`: typography, responsive layout, and visual styling.
- `assets/chess-timesheet.png`: screenshot of the Chess Tournament Timesheet, previously published in the profile README.
- `.nojekyll`: tells GitHub Pages to serve the static files directly.

The site uses native links and expandable experience entries and remains functional without JavaScript. It contains no trackers, forms, or backend services.

## Local preview

From this directory, run:

```sh
python -m http.server 4173 --bind 127.0.0.1
```

Then visit `http://127.0.0.1:4173`.

## Publishing

GitHub Pages publishes the root of the `main` branch. Editing and pushing the static files updates the site.

## Content

Professional background is based on the supplied resume, the GitHub profile README, and previously verified LinkedIn experience. Work experience is the main focus, with all five roles expanded by default. A compact Chess Tournament Timesheet feature connects engineering with personal interests; its description is grounded in the public project repository.
